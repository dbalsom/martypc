# Contributing

Human contributions are welcome. PRs for bug fixes or corrections to documentation are greatly appreciated. 

Before starting a substantial change or implementing a new feature, please open an issue or discussion post to inform me of what you would like to work on. There are several things that I would prefer to implement myself, and many things that may be impacted by future refactoring plans.

When submitting a pull request:

* Keep changes focused on one issue / problem / feature.
* Explain what you changed and why.
* Describe how you tested it.
* Follow the surrounding code’s style and conventions.
* Use rustfmt with the `+nightly` flag to properly parse this project's `rustfmt.toml`.

Please submit work you understand and can explain during review. Automated submissions from AI agents will not be accepted.
