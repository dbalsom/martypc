
# /crates/lib

## marty_common
- This crate defines types and interfaces that are common between frontends and MartyPC's core.

## marty_core
- This crate contains the main emulator core functionality. It is intended to be independent of windowing system, rendering backend, sound backend, or other implementation-specific details.

## marty_vhd
- This crate contains functionality for creating and working with VHD files, shared between MartyPC's core and frontend.
